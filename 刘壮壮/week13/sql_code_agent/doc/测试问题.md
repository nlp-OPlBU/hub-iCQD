# SQL Code Agent 测试问题

答案全部按原始库 `data/chinook.db` 核对过，没有包含 `data/test_seed.sql`。金额单位是美元，保留两位小数。只要最终回答里的国家和数字与下表一致，就算通过。

建议按下面顺序测：先单表，再汇总，再跨表。第 23–25 题用来看「SQL 校验」会不会拦住改库语句。

## 二、汇总：和国家、年份、客服有关

### Q6. 哪个国家的客户买音乐花钱最多？

- 应该用到的表：`invoices`（按 `BillingCountry` 汇总 `Total` 即可，不必再连客户表）
- 期望答案：美国（USA），523.06 美元。其后是加拿大 303.96、法国 195.10、巴西 190.10、德国 156.48。

### Q7. 客户人数最多的是哪个国家？

- 应该用到的表：`customers`
- 期望答案：美国（USA），13 位。加拿大 8 位，法国和巴西各 5 位。

### Q8. 全店一共卖了多少钱？账单从哪天到哪天？

- 应该用到的表：`invoices`
- 期望答案：412 张账单，合计 2328.60 美元。最早 2009-01-01，最晚 2013-12-22。

### Q9. 哪一年的销售额最高？

- 应该用到的表：`invoices`
- 期望答案：2010 年，481.45 美元。各年分别是：2009 年 449.46、2010 年 481.45、2011 年 469.58、2012 年 477.53、2013 年 450.58。

### Q10. 哪位客服负责的客户最多？

- 应该用到的表：`employees`、`customers`
- 期望答案：Jane Peacock（Sales Support Agent），21 位。Margaret Park 20 位，Steve Johnson 18 位。总经理、销售经理和 IT 员工名下没有客户。

### Q11. 花钱最多的客户是谁？

- 应该用到的表：`customers`、`invoices`
- 期望答案：Helena Holý（捷克 Czech Republic），49.62 美元。第二是 Richard Cunningham（USA）47.62，第三是 Luis Rojas（智利 Chile）46.62。

## 三、跨表：歌曲、流派、歌手

### Q12. 哪个流派卖得最多？

- 应该用到的表：`invoice_items`、`tracks`、`genres`
- 期望答案：Rock，826.65 美元，卖出 835 份。其后是 Latin 382.14、Metal 261.36、Alternative & Punk 241.56。

### Q13. Rock 流派一共有多少首曲目？

- 应该用到的表：`tracks`、`genres`
- 期望答案：1297 首。全库共 25 个流派。

### Q14. 曲目最多的歌手是谁？

- 应该用到的表：`artists`、`albums`、`tracks`
- 期望答案：Iron Maiden，213 首，分布在 21 张专辑里。其后是 U2 135 首、Led Zeppelin 114 首。

### Q15. 销售额最高的歌手是谁？

- 应该用到的表：`invoice_items`、`tracks`、`albums`、`artists`
- 期望答案：Iron Maiden，138.60 美元。其后是 U2 105.93、Metallica 90.09、Led Zeppelin 86.13。

### Q16. AC/DC 有哪些专辑，每张有几首歌？

- 应该用到的表：`artists`、`albums`、`tracks`
- 期望答案：两张。*For Those About To Rock We Salute You* 有 10 首，*Let There Be Rock* 有 8 首。

### Q17. 时长最长的曲目是哪一首？

- 应该用到的表：`tracks`，要带上歌手再加 `albums`、`artists`
- 期望答案：*Occupation / Precipice*，来自 Battlestar Galactica，5,286,953 毫秒（约 88.1 分钟）。它是影视配乐，不是普通单曲。

### Q18. 歌单 Classical 里有多少首曲目？

- 应该用到的表：`playlists`、`playlist_track`
- 期望答案：名字正好是 `Classical` 的歌单有 75 首。另外三条 Classical 101 歌单（Deep Cuts、Next Steps、The Basics）各 25 首，不要和这条混在一起。

## 四、空结果和容易查错的问法

### Q19. 有没有中国客户？

- 应该用到的表：`customers`
- 期望答案：没有。`Country = 'China'` 的客户是 0 位。不要把「查不到」说成查询失败。

### Q20. 有没有没填公司名的客户？

- 应该用到的表：`customers`
- 期望答案：有。59 位客户里 49 位的 `Company` 为空。

### Q21. 曲目单价有哪几档？

- 应该用到的表：`tracks`
- 期望答案：只有两档。0.99 美元的有 3290 首，1.99 美元的有 213 首。

### Q22. Jane Peacock 负责的客户一共消费了多少？

- 应该用到的表：`employees`、`customers`、`invoices`
- 期望答案：833.04 美元。注意是按客户的 `SupportRepId` 汇总，不是按员工自己的购买。
