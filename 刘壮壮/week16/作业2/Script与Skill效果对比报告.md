# Script 与 Skill 效果对比（真实检索数据）

## 实验数据

- 检索日期：2026-11-24。
- 时间范围：2024-11-24 至 2026-11-24。
- 输入：`data/esg_tender_search_2024-11-24_to_2026-11-24.csv`，本次真实搜索形成的24条记录，不含合成样本。
- Script：`scripts/tender_report.py`，按相同时间窗口筛选、精确去重，并分别统计中标/成交、候选人公示和招标公告，汇总金额缺失、年份及金额区间。
- Skill-only 基线：对同一 CSV 逐条核对日期、状态、金额口径和重复项，再独立汇总；不调用统计 Script。来源核验仍按同一规则处理。

## 效果判断

Script 对日期筛选、重复计数、状态分组、缺失值处理、金额统计和重复生成结果有直接帮助。把中标、候选报价与采购预算分开汇总，可减少混算风险；金额区间和分年度统计也能稳定复跑。

Script 不判断项目是否真正属于 ESG，不核验公告是否后来撤销，也不能识别跨平台镜像公告的语义重复、核实搜索摘要是否与附件一致，或分析项目对客户的价值。这些任务仍由 Skill 的研究流程和人工复核承担。

本轮没有记录 Skill-only 手工操作耗时，因此不报告虚构的速度提升；也没有对来源事实准确率作统计推断。金额汇总准确性只表示在这24条已收集记录和当前字段口径下两种汇总一致，不代表样本覆盖完整或来源均已取得全文。
