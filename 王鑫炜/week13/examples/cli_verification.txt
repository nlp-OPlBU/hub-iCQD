$ python sql_agent.py --demo --max-rows 2 消费金额最高的前 3 位客户是谁？
模式：离线固定案例（未调用模型）
流程：parse_database -> select_tables -> generate_sql -> validate_sql -> execute_sql -> summarize
选表：customers, invoices
SQL：SELECT c.CustomerId, c.FirstName || ' ' || c.LastName AS customer_name, ROUND(SUM(i.Total), 2) AS total_spent FROM customers AS c JOIN invoices AS i ON c.CustomerId = i.CustomerId GROUP BY c.CustomerId, c.FirstName, c.LastName ORDER BY total_spent DESC, c.CustomerId ASC LIMIT 3;
修复次数：0
回答：查询结果：[{"CustomerId": 6, "customer_name": "Helena Holý", "total_spent": 49.62}, {"CustomerId": 26, "customer_name": "Richard Cunningham", "total_spent": 47.62}]这里只展示前 2 行预览，不能据此判断全量结果。
退出码：0
