# 检索与统计口径

## 查询矩阵

| 主题 | 检索词组合 |
| --- | --- |
| ESG 披露与评级 | `ESG报告`、`可持续发展报告`、`社会责任报告` 与 `编制`、`鉴证`、`评级`、`披露` 交叉 |
| 双碳核算与履约 | `碳排放`、`温室气体`、`碳足迹`、`碳标签`、`碳盘查` 与 `核查`、`核算`、`存证`、`碳数据`、`履约` 交叉 |
| 绿色低碳规划 | `双碳`、`减污降碳`、`碳达峰`、`零碳园区` 与 `行动方案`、`路径`、`评价`、`规划`、`平台` 交叉 |
| 可持续供应链 | `绿色采购`、`绿色供应商`、`范围三`、`供应链碳排放` 与 `评价`、`平台`、`咨询` 交叉 |

成交回顾追加 `中标公告`、`成交结果`、`中选结果` 等，并分别检索最近四个半年段。每日模式追加 `公开招标`、`采购公告`、`磋商公告`、`询比` 等，至少检索近两个自然日，将采购编号追加 `更正`、`澄清`、`终止`、`流标`、`重新招标` 对重点项目复查。使用搜索引擎时可限定 `site:ccgp.gov.cn`、各省市政府采购和公共资源交易域名、`site:bidding.csg.cn` 或 `site:ebid.chinatowercom.cn`。以采购人官方文件、指定公告平台、交易平台公告为证据。

以采购交付物确定主主题，保留有用的辅助标签。碳配额日常交易行情、仅采购人名称含关键词、只在单位园区名中出现「双碳」的普通工程，排除。采购规划、招采意向、候选人、废标、合同公示和最终结果各有独立阶段。

## 归档与金额

| 字段组 | 核验内容 |
| --- | --- |
| 证据 | 原文标题、原文 URL、来源、页面明示时间及首次发现时间 |
| 主键 | 采购人、编号体系、项目编号、包号、采购轮次 |
| 内容 | 主主题、采购范围、成交人、公告类型与最新状态 |
| 金额 | 原文值和单位、金额类型、可比较的币种及人民币值、税口径、服务周期 |
| 日更 | 文件获取截止、投标截止、报名条件、后续更正链接 |

采购包之间独立，若某份公告标题看似单一包号、正文列出了多包，逐包摘取，并将项目数计一次。同一编号的重新招标记为新公告版本，确认旧结果是否失效。相同金额可能出现在公告概况、采购结果、标的明细、合同公示中，以同一成交标包计一次。候选报价、预算、最高限价、元／吨等单价、费率、合同框架上限、代理费均有独立类型。只公开单价时，除非原公告还确认成交总量和结算口径，否则归入总金额未披露。注意多年度合同按合同全周期比较，并披露年限；按年分析时先核实可年化的服务期限。

默认金额段按人民币万元使用 `低于 20`、`20 至低于 50`、`50 至低于 100`、`100 至低于 300`、`300 及以上`。百分比注明分母；样本小的时候展示中位数、范围和个案，避免以均值代替典型报价。发布数量和金额可受单双季窗口、采购项目拆包、某一大买方和平台索引影响。

## 每日运行时规则

建议每天 09:00 Asia/Shanghai 检查，扫描从上次成功时点到本次时点。为补偿收录延迟，每轮回看最近三日并使用项目、包号、公告阶段与变更字段去重。首次运行先建立已发现记录；将首次发现但发布日期较早的条目标注为「补录」。「新增」只用于新出现的公告，「更新」只用于截止、资格、标包或采购状态有实质变化。每条机会优先按文件获取／报名和递交两道门槛中更早的一项排序，再结合资格和主题相关度。对变更、撤销和已报名供应商的递交提醒分别列清。

若已授权创建定时任务，任务正文应给出来源、主题、时区、扫描窗口、结果渠道和状态持久位置；运行成功后推进对应来源水位。空结果正常运行时输出「本轮覆盖来源未检出可行动新增」，失败源写明暂缺。默认在任务自身会话生成摘要；推送到外部渠道需要用户提供并明确授权收件人及渠道。
