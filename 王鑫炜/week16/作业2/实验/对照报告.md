# ESG Skill 有脚本／无脚本对照

同一批已核验证据交给两种实现后，两组得到相同的中标数、成交金额分布和新增招标名单。脚本把统计、日期筛选和逐条剔除依据固定下来；纯 Skill 直接写出的报告更容易把事实转化为影响和行动。独立联网实测还显示，新闻索引会遗漏采购公告，官方原文检索和核验仍会影响最终覆盖。

## 实验怎么做

- **固定输入。** 两组都使用 [月报证据](../数据/月报证据.json) 和 [招投标证据](../数据/招投标证据.json)。月报窗口为 2026-10-01 至 10-31，成交窗口为 2024-11-27 至 2026-11-26。日报接收 11-25 至 11-26 的公告，判断截点为 11-26 10:00（北京时间）。哈尔滨公告使用的站内栏目链接统一为更稳定的原文入口，其他字段保持一致。
- **A · Skill 直接处理。** 两个独立会话分别读对应 Skill 和相同证据，直接用模型筛选、汇总、写报告。各运行一次，未使用计算脚本、计算器或追加检索，提交初次输出。 [A 月报](A-月报.md) · [A 招投标](A-招投标.md)
- **B · Skill 接入确定性脚本。** Python 先用同一规则处理证据，输出分组摘要、筛选记录、统计表和推送底稿。固定输入和参数重跑，再用 `cmp` 比较 Markdown。下表评价实际脚本输出。最后的业务研判可以由 Skill 继续完成。 [B 月报](B-月报.md) · [B 中标](B-中标.md) · [B 日报](B-日报.md)
- **另做在线试跑。** 在真实网络环境测试搜索和候选摘要。在线试跑衡量查询行为和输出可复跑性，固定证据实验衡量归纳计算，两者对应不同环节。 [联网记录](联网检索/README.md) · [候选摘要](联网检索/候选摘要.md)

## 实际结果

| 检查项 | A · 无脚本 | B · 有脚本 |
| --- | --- | --- |
| 月报纳入数和主题 | 12 条，分组 4／2／4／2 | 12 条，分组 4／2／4／2 |
| 月报事实及状态 | 核对 M03 方法学、M06 事故发生和公开日期、M07 拟收购、M11 工程阶段、M12 意见截止，给出 3 项优先行动 | 保留原文链接和时间字段，以上事实状态均可定位。提取内容保留拟议／生效等原文状态 |
| 成交样本 | 13 个项目、25 个单元，23 个可比总价，2 个缺失 | 13 个项目、25 个单元，23 个可比总价，2 个缺失 |
| 金额和分箱 | 总额 47,707,099 元，中位数 2,850,000 元，范围 189,500 至 5,196,800 元，五档 0／11／0／11／1 | 相同。程序另算出最大项目占已知金额 81.70% |
| 公告阶段 | 说明 P24 是候选，P26 是最终结果，P27 报名已结束 | P24 从中标统计剔除，P26 从日报机会剔除，P27 超出新增窗口，记录可追查 |
| 日报可行动 | P28、P29 共 2 条，列出两道截止时间和行动 | 同两条，同四项截止时间，列出逐条原文 |
| 复跑 | 各案例 1 次 | 三份 Markdown 各重跑 1 次，均逐字节一致 |

金额分箱为人民币万元，依次使用低于 10、10 至低于 50、50 至低于 100、100 至低于 500、500 及以上。两组都排除了未披露金额。正文成交报告另用 Skill 默认分箱，并对江苏多包项目做了去除后的敏感性分析。

A 月报能把 M06 的安全风险连到演练、现场验收和整改闭环。它在管理层摘要中把推荐性标准与征求意见节点描述成「要求」报告团队实施，语义偏强。详细段落已区分制度状态，正式月报表述为建议提前做字段映射并跟踪正式文本。B 能保留制度阶段，最终建议仍需要结合适用规则。A 的采购报告解释了多包项目怎样抬高双碳主题频次，B 自动给出项目计数和 81.70% 的集中度。实务上，285 万元的样本中位数同时混入软件系统和多年服务，报价前还应按交付物和周期找可比标的。

## 联网与复核

- 2026-11-26 10:46:30，脚本向 Google News RSS 发送 4 个查询，原始返回 22、2、10、0 条，限额与去重后共有 12 条候选。候选多为聚合链接，最近采购窄检索式成功请求后返回 0 条。政府和企业原文检索能够核验实际招标，因此该查询的空结果只能解释为新闻索引未命中。原始响应离线重放后，记录、排名与查询统计均一致。
- 独立复核重新查询两条招标的原件，确认哈尔滨项目先下载文件并在 12 月 4 日 13:00–13:30 现场递交。南方电网项目要完成供应商登记、获取文件和电子证书办理，并核对审计报告与资格。部分采购站点仍出现限流或验证页，简报需保留受影响来源的扫描水位，后续补扫。 [哈尔滨原文](https://hrbggzy.harbin.gov.cn/cqjy/003008/003008001/20261125/465c7647-511f-4ec4-9383-2c8865cdaaca.html) · [南方电网原文](https://www.bidding.csg.cn/zbgg/1200451686.jhtml)
- 自动测试覆盖重复项目包、不同包分别计数、金额边界、跟踪参数去重、预算与单价排除、同日发布截点、报名时间和终止更新，以及失败快照提示。真实证据回放与边界测试分别验证稳定重跑和容易出错的业务口径。

## 复跑命令

从 `作业2` 目录运行。

```bash
python3 scripts/summarize_esg.py monthly 数据/月报证据.json > /tmp/esg-b-monthly.md
python3 scripts/summarize_esg.py awards 数据/招投标证据.json \
  --bins-wan 10 50 100 500 > /tmp/esg-b-awards.md
python3 scripts/summarize_esg.py daily 数据/招投标证据.json \
  --since 2026-11-25 --at 2026-11-26T10:00:00+08:00 > /tmp/esg-b-daily.md
cmp 实验/B-月报.md /tmp/esg-b-monthly.md
cmp 实验/B-中标.md /tmp/esg-b-awards.md
cmp 实验/B-日报.md /tmp/esg-b-daily.md
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
```

这次只有两个单案例的 A/B 对照，输入已预先核验，未测耗时、模型费用、跨月份表现或全市场召回率。可复跑性结论限定在保存的原始响应或同一份证据与参数。每次正式运行仍应由 Skill 核验原文、补足覆盖，并完成面向使用者的优先行动和判断。
