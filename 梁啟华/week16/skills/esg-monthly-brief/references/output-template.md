`scripts/check_brief.py` 的结构校验依据，请勿改名。

```markdown
> 生成日期：YYYY-MM-DD

- **对客户影响**：<影响的业务单元、成本项或披露章节；尽量量化>
- **可观测信号**：<未来 1-6 个月可观察到的信号>
- **置信度**：高/中/低——<依据>
- **来源**：[<信源名称>](<链接>)

### 案例二：…（共 2-3 个案例）

```

## 写作约束

1. 每条政策必须含“变化 / 作用机制 / 对客户影响 / 可观测信号 / 来源”。
2. 每个案例必须含“问题 / 做法 / 投入与成果 / 可复制条件”。
3. 跟踪点必须含**时间 + 信号 + 验证方式 + 判定规则**。
4. 所有链接使用 `[名称](URL)` 形式；无法确认的链接不写，改写“来源：<机构> <报告名> <日期>”。
5. 表格中缺数据写“未披露”，不留空。
