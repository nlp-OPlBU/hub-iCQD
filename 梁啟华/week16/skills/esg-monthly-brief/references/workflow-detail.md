# 月报执行细则（workflow-detail）

本文件是 `SKILL.md` 执行流程的展开说明。**只在本技能被触发、且需要具体判断标准时加载。**

## 总原则

1. **先判断，再罗列。** 每一条信息都必须回答“对客户意味着什么”，否则不进入简报。
2. **事实与推断分开写。** 事实注明来源；推断注明依据与置信度（高/中/低）。
3. **宁可留缺口，不可补数据。** 查不到就写“数据缺口 + 已尝试的信源”。
4. **时间窗内。** 只收录 `time_window` 内发布或生效的内容；跨期事项写入跟踪点，不混入当期动态。

---

## S0 检索范围声明

正式检索前，先输出一行范围声明，并在最终简报末尾复用：

```text
检索范围：YYYY-MM-DD 至 YYYY-MM-DD；信源层级 [A/B/C/D]；地区 [全球/中国/某省]；
关键词组 [政策、评级、标准、披露准则、行业实践]；已知缺口 [无法访问的信源]。
```

检索范围应覆盖 `references/source-guide.md` 中与客户行业相关的 A/B 级信源；C/D 级仅作线索。

---

## S1 候选筛选：影响强度评分

先收集 ≥8 条候选，再按下表逐条打分（1-5），保留 3-5 条得分最高者：

| 维度 | 说明 | 权重 |
| --- | --- | --- |
| 直接约束力 | 是否强制适用于客户主体（法规 > 标准 > 倡议） | 高 |
| 成本影响 | 是否改变合规成本、技改投入、碳成本 | 高 |
| 披露义务 | 是否新增/收紧对外披露要求 | 中 |
| 融资影响 | 是否影响信贷、债券、评级 | 中 |
| 竞争格局 | 是否改变同行门槛 | 低 |
| 时效性 | 是否在 1-3 个月内落地 | 低 |

> 评分相同则优先“直接约束力”高者。落选候选不必写入简报，但可在“数据缺口/附录”中一行带过。

## S2 传导判断模板

每条政策/评级/标准动态都必须按下列五段式书写：

```text
【变化】谁在什么时间发布了什么，核心要求/口径变化是什么（一句话）。
【作用机制】通过什么路径影响企业：强制约束 / 成本传导 / 披露口径 / 融资条件 / 供应链要求。
【客户影响】对 <client_company> 的具体影响：影响的业务单元、成本项或披露章节；
          尽量量化（区间、比例、时间点），无法量化时写“影响规模待评估”。
【可观测信号】未来 1-6 个月可观察到什么（监管动作、同行披露、价格/成本变化）。
【置信度】高/中/低 + 一句依据。
```

**反例（禁止）**：“该政策体现了国家对 ESG 的重视，对行业整体利好。”
**正例（示意）**：“核算指南将煤电纳入月度存证范围（变化）→ 企业需按月留存燃料与排放数据（机制）→ 客户两座坑口电厂需新增计量点位与台账岗位，合规成本上升（影响）→ 观察省内其他煤电企业是否发布存证培训/招标（信号）。”

## S3 行业实践拆解模板

每个案例必须可拆解，不得只写“某公司发布 ESG 报告，值得借鉴”。按四段式：

```text
【问题】案例企业面对的具体约束或痛点（与其业务绑定）。
【做法】采取的动作、组织安排、技术手段（写到可复述的程度）。
【投入与成果】投入（人力/资金/时间）与可验证成果（数据、评级、认证）。
【可复制条件】对 <client_company> 的适用条件：哪些能直接照做、哪些依赖资源禀赋、
             哪些存在合规/成本障碍。
```

优选来源：企业 ESG/可持续报告、CDP 披露、评级机构案例、行业协会白皮书。

## S4 张力识别

**张力 = 客户公开承诺与其资源能力、业务现实之间的真实矛盾。** 常见类型：

| 类型 | 识别问题 |
| --- | --- |
| 承诺 vs 能力 | 披露/减排承诺是否有对应的数据体系、预算、组织？ |
| 目标 vs 增长 | 减排目标与产量/装机增长是否冲突？ |
| 标准 vs 口径 | 对外披露口径与内部核算口径是否一致？ |
| 成本 vs 竞争 | 合规投入是否削弱成本优势？ |
| 供应链 vs 控制力 | 范围三目标是否依赖无法控制的供应商？ |

写法要求：

- 至少 1 个张力，必须有**证据**（客户披露原文、公告、行业数据）与**影响判断**。
- 若检索后确无显著张力，写：“未识别到显著张力。已检索 [信源/关键词]，判断依据：[…]”。不得为了凑数编造矛盾。

## S5 同行对标

选 2-3 家同行，使用同一张维度表，缺数据的格子写“未披露”，不要留空或猜测：

| 维度 | 客户 | 同行A | 同行B | 同行C |
| --- | --- | --- | --- | --- |
| 披露标准/框架 | | | | |
| 核查/鉴证覆盖 | | | | |
| 气候目标与时间表 | | | | |
| 碳资产/碳交易动作 | | | | |
| 治理架构（董事会层级） | | | | |
| 评级表现（如有） | | | | |

对标结论必须落到“差距在哪、是否紧迫”，而不是只展示表格。

---

## S6 结论与跟踪点

**月度结论**：1 段话，回答“本月最重要的一个变化是什么，客户下个月应该做什么”。

**跟踪点**：恰好 3 个（可多不可少），每个必须可证伪：

```text
- [跟踪点] 预期在 <时间窗> 出现 <具体信号>；验证方式：<信源/渠道>；
  判定：若 <信号> 出现则 <判断A>，否则 <判断B>。
```

不合格示例：“持续关注政策变化。”
合格示例：“2026-01 前，示例省是否发布煤电月度存证细则；验证方式：省生态环境厅官网；若发布则客户需在 Q1 完成计量改造，否则窗口顺延至 Q2。”

---

## 常见退化模式（自查）

- 信息平行罗列，没有传导判断；
- 把新闻摘要当分析，结论只有“利好/利空”；
- 对标只列同行优点，不写客户差距；
- 张力写成“挑战与机遇并存”；
- 跟踪点无法验证（“持续关注”“加强跟踪”）；
- 数据没有来源或来源为二手转述。
