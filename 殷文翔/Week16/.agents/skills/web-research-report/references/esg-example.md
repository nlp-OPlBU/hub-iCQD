# ESG 月报检索与编辑参考

## 来源和检索路径

| 主题 | 优先核对 | 补查思路 |
| --- | --- | --- |
| 中国政策与监管 | 中国政府网、发改委、财政部、生态环境部、行业主管部门和地方实施机构 | 用文件名或文号找原文和附件。查受管主体所在省市名录、适用条件与执行时间。 |
| 披露和标准 | 财政部、证监会、上市地交易所、IFRS Foundation、ISO、相关标准发布机构 | 用项目号、标准号或征求意见题名找最新阶段。区分初稿、立项、正式发布和实施。 |
| ESG 评级 | Wind、MSCI、标普全球或其他评级机构的公司页、变更说明和方法页 | 用机构名、股票代码和日期查评级与分值的变更记录。跨机构结果各自解释。 |
| 行业和实践 | 官方统计、行业监管、协会、案例企业和项目业主 | 用业务加议题找统计发布、停限产、保供、项目节点、处罚或整改。用负责人或项目全称找原始披露。 |
| 客户和同业 | 交易所公告、公司投资者关系页、ESG 报告、监管处罚与整改公示 | 查代码、公司简称、控股股东和项目主体。先确认事项属于哪个主体，再判断对客户的影响。 |

中国煤炭、电力及煤化工客户可从经营链条入手：

- 煤炭开采关注矿山安全、承包商、煤矿甲烷、矿井水和矿区复垦。组合搜索企业简称、矿名、甲烷监测、取水许可、隐患、整改或事故。
- 发电关注碳市场履约、供热保供、煤电灵活性、新能源及实际发电量。组合搜索电厂、重点排放单位名录、配额、投运、调峰或供热。
- 煤化工关注取水和排水约束、工艺安全、项目许可、生命周期排放。组合搜索项目名、关联交易、签约、交割、环评、取水和试运行。
- 运输关注铁路与港口周转变化、物流保供、装卸扬尘与安全。组合搜索码头、铁路、吞吐量、恶劣天气或清洁运输。
- 中国神华示例可用中煤能源或兖矿能源观察煤炭开采及煤化工，用中国华电集团等观察煤电运营实践。控股集团的技术展示可用于分析客户可获得的支持，集团成果的覆盖范围仍需核对。

## 取舍和核算例子

- 区分发布时间和数据时间。11 月披露的 10 月经营数据可纳入 11 月月报，必须标出所属月份。旧年度 ESG 报告中的量化指标可用作基准，并说明报告年度。
- 同一规则的草案和正式文件可能规定不同的完成时间。用正式文本确认现行要求，并核对是否另有修订。评级机构同一公司的中英文页面也可能显示不同日期的快照。引用时保留各自的更新日，仅在方法和主体口径一致时比较。
- 区分立项与合规。煤矿甲烷监测国际标准处于立项时，可以提出计量准备建议。现行合规判断应另查适用的国内标准及地方要求。
- 区分股权比例与统计边界。50% 股权交易签约可触发碳、水、工艺安全和关联治理尽调。是否交割、财务合并、温室气体组织边界及后续披露范围各有判断依据，应查公告和相应核算规则。
- 对运营量使用恰当分母。全国原煤与公司商品煤、总发电量与燃煤发电量、项目装机与实际发电量属于不同指标。并列时说明口径，不从增减幅度直接推断市场份额、实际排放或减排成效。
- 写明对标动作的可迁移条件。例如发电集团投产热电联产项目可用于研究供热可靠性与新能源联营考核，实际环境绩效需结合运行期发电、供热和绝对排放数据判断。

## 交付前审阅

1. 检查所有重点事实的原文链接和日期。报告中的标题、图表、摘要与正文引用同一组数据和状态。
2. 检查单位、百分比与百分点、同比与环比、累计与当月、基期重述、组织边界和项目主体。政策或标准的关键期限及适用条件有直接来源。
3. 检查摘要中的每项优先事项是否在正文有证据、在行动表有可操作的回应。行业和同业案例至少说明一个可迁移做法及可衡量的结果或跟踪指标。
4. 在正式文件中把来源链接放在相关条目末或表格说明中。跨页检查页标题、表头、分页及数字可读性。正文可附方法和数据限制，客户无需依赖聊天记录理解报告。
