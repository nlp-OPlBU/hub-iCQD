# ESG Skill 有脚本与无脚本对比

有脚本和无脚本两种流程得出了相同的核心事实、金额和日报增量。差异主要体现在审计和复跑。代理可直接写出带因果说明与行动建议的报告，脚本则让链接去重、日期筛选、金额计算和历史对照有固定规则与可检查的输出。

## 实验设置

同一案例使用相同的观察期、候选来源、公告字段与报告要求。案例一固定 12 条联网候选，加入一条带跟踪参数的重复链接，用于测试去重。案例二使用同一份两年样本和同一批 7 条日报候选，按北京时间 2026 年 11 月 27 日 11:20 对比 11 月 26 日的两份历史归档。

- **无脚本**使用内置网页工具检索或打开来源，代理按同一业务口径手工核查日期、去重、归档状态、内容和引用，然后直接撰写月报与日报。两年样本的合计、中位数与金额区间在下表列出复算依据。 [月报](无脚本月报.md) · [日报](无脚本日报.md)
- **有脚本**使用联网搜索发现候选，代理核验原文并提炼事实，Python 负责网址归一、日期筛选、引用校验、金额汇总和日报去重。批量检索入口 `search_web.py` 支持 Brave API，本次环境无对应密钥，月报输入采用内置网页搜索所得候选。招采定时任务通过 `daily.py` 调用 Codex CLI 进行实时联网检索。 [月报候选](月报候选.json) · [月报筛选结果](月报筛选结果.json) · [有脚本月报](有脚本月报.md) · [中标统计结果](中标统计结果.json) · [有脚本日报](日报回放/2026-11-27_112000.md)

## 实测结果

| 检查项 | 无脚本 | 有脚本 |
| --- | --- | --- |
| 月报候选 | 逐条核对 12 条候选。将带跟踪参数的矿山安监通知与原链接合并。交易原公告和国内现行甲烷标准作为背景。ISO 研制状态与本期立项消息一起核对。 | 输入 12 条，合并 1 条重复链接，标记 2 条窗外资料，保留 9 条窗内或日期待核候选。脚本保留 ISO 未注明发布日期的项目页。 |
| 月报内容 | 三节短报沿管理决策组织。说明矿山联网时限、行业产量、甲烷监测试点、华电行动以及煤制气交易签约状态。 | 同一来源池生成三节短报，事实与分析关联来源 ID，正文与索引可跳转。交易原公告作为背景支持金额与交割后股权结构。 |
| 两年中标统计 | 37 条样本，35 条有金额。按 7 档数得 0、4、6、6、18、0、1 条。排序后第 18 笔为 112.01 万元。分档金额相加为 70,837,772 元。 | 样本数、7 档笔数、总额与中位数均一致。程序保留未披露金额，使用十进制数计算，并输出按年、主题、金额分档和剔除最大单包的结果。 |
| 日报增量 | 7 条候选逐条与两份历史日报核对，排除哈尔滨同项目的两个链接、已归档宁波线索和过期福建项目，得到 0 条新增、1 条重大变更、2 条待核。 | 同口径回放得出相同的 3 条记录。程序同时输出结构化 JSON 和 Markdown，可直接检查归档与截止时间。 |
| 异常输入 | 需要定期逐项复查历史记录和引用。 | 验证时加入重复标包或未知来源 ID，程序报告错误并返回非零状态。重复执行相同配置，生成内容保持一致。 |

同一份输入的复跑主要验证规则与数据处理。新增搜索命中量由索引覆盖、检索词和公告可访问性决定，内容质量仍取决于能否区分正式规则与标准研制、签约与交割、预算与成交金额。此次未计量工作总耗时和模型调用成本。

## 复现命令

在 Week16 目录下使用 PowerShell 和 Python 3.10 或以上版本。文件均为 UTF-8。日报历史通过 `--history` 指向原归档目录，回放结果写入作业 2 目录。

```powershell
$research = '.agents/skills/web-research-report/scripts'
$procurement = 'ESG招采/esg-procurement-monitor/scripts'
$ab = '作业2对比'

python -X utf8 -B "$research/triage_sources.py" "$ab/月报候选.json" --start 2026-10-27 --end 2026-11-26 --output "$ab/月报筛选结果.json"
python -X utf8 -B "$research/render_report.py" "$ab/月报简报.json" --output "$ab/有脚本月报.md"
python -X utf8 -B "$procurement/summarize.py" 'ESG招采/中标样本.json' --start 2024-11-27 --end 2026-11-26
python -X utf8 -B "$procurement/daily.py" --input "$ab/日报候选.json" --as-of '2026-11-27 11:20' --history 'ESG招采/日报' --output "$ab/日报回放"
```

批量联网检索的参数、查询文件结构与候选输出见[联网搜索脚本说明](../.agents/skills/web-research-report/references/scripts.md)。日报回放使用已核验的候选与历史归档，无需联网和推送。
