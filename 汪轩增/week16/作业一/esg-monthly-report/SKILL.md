# ESG 月报

为用户指定的企业或客户生成有时效性、可追溯且能支持行动的 ESG 月报。默认报告期为最近一个完整自然月；用户可以指定其他周期。可用中国神华作为示例，但不可将示例设为固定客户。

## 工作方式

1. 确认对象、行业、地区和报告周期。缺少信息时，根据上下文作合理假设，并在报告中披露。
2. 使用可用的互联网搜索工具自主检索。优先找政策制定者、标准组织、评级机构、企业公告/ESG报告、交易所和可靠行业媒体的一手材料。使用多组中英文关键词，覆盖政策/标准、评级、行业实践、公司动态及争议/负面事项。
3. 按实际发布时间和事件发生时间分别记录。只将报告期内新发布或新发生的事项列为本期动态；历史信息只作为背景并标明日期。
4. 对重要事实尽可能回到原始来源核实；合并转载和重复报道。筛除日期不明、来源薄弱、与对象关系牵强或无法验证的内容。不要把搜索摘要当作已核实证据。
5. 为每条保留标题、发布者、发布日期、事件日期、链接、事实摘要、影响对象、影响方向/期限、证据强度和建议。事实、推断和建议要分开写；不要暗示未经来源支持的因果关系。
6. 综合政策/评级/标准、行业动态/最佳实践、公司动态三个必备部分，分析重大性、机遇风险和可执行行动。最佳实践需解释其可借鉴点，不能只罗列案例。

## 报告交付

使用中文，标明企业、行业、地域、报告期、检索日期和口径。先给执行摘要与优先级最高的三项影响，再按上述三个必备部分组织。每项重要结论附近放可点击来源链接及日期，末尾提供来源清单。注明信息缺口、尚未核实事项和分析假设；不得编造搜索结果、评级或数字。若结果稀少，应如实说明并简述检索覆盖范围。

用户要求时可将检索结果整理为 `scripts/esg_pipeline.py` 支持的 JSON 结构，并用该脚本生成可复核的条目清单；脚本输出是整理辅助，不替代网页核查和专业判断。
